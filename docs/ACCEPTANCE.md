给"改完之后照着点一遍"用。**每项都写清：怎么操作、预期是什么、不符合时先查哪里。**

- 环境基线：Windows 11、**显示缩放 125%**、双屏（主屏 2048×1152 @ (0,0)）。
  缩放与多屏都要覆盖——这两块踩过坑（DPI 虚拟化坐标、HUD 被钳到屏顶）。
- 建议顺序照抄：先做 A（环境），再做 B–I（功能），最后 J–K（异常与资源）。
- 所有"预期日志"都在 `%APPDATA%\dev.lunar.lemma\logs\lemma.log`。

UI 重做的每个阶段都单独构建 + 单独提交，并在真实窗口上核对：

| 截图对照 | ✅ | 并排：图上细框带编号 + 右栏编号译文、悬停同步；覆盖：实色原位翻译 + 实色气泡 |

顺手修掉一处内存浪费：框选层用完从"隐藏"改为"销毁"，
OCR 之后整棵树从 **306.1 MB 降到 253.5 MB（−52.6 MB）**，进程数回到 7。

**仍未由自动化覆盖**：朗读的实际听感、设置里「点击录制」与「恢复默认」的真实点击
（任务栏自动隐藏，托盘图标点不到）、多屏相关项（副屏已断开）。
