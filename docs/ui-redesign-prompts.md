# Lemma UI 重设计提示词

这套提示词用于让设计模型重新设计 Lemma 的桌面 UI，重点是避免常见的“AI 配色味”：蓝紫渐变、青色霓虹、玻璃拟态、发光边框和 SaaS 仪表盘风格。

## 总提示词

```text
为 Lemma 设计一套 Windows 桌面阅读辅助工具 UI。

Lemma 的核心体验是：
用户在网页或文档中选中单词、句子或截图区域后，通过快捷键获得词义、翻译、OCR 结果和朗读功能。界面需要服务于高频阅读，用户会长时间使用，因此必须克制、安静、清晰，像一个成熟的桌面生产力工具，而不是营销网站或 AI 聊天产品。

视觉方向：
- editorial desktop utility
- quiet reading tool
- restrained information design
- mature Windows application
- calm, tactile, slightly literary
- inspired by text editors, annotation tools and professional reading software
- dark graphite interface with warm neutral tones

配色：
- 背景使用深石墨色、炭黑色和暖灰色
- 面板使用略亮的灰褐色
- 正文使用暖白色
- 次要文字使用低对比度灰色
- 只使用一个低饱和强调色，推荐陶土橙或暗橄榄绿
- 强调色只用于当前状态、选中边框、关键操作和链接
- 禁止蓝紫渐变
- 禁止青色霓虹
- 禁止彩色光晕
- 禁止高饱和渐变
- 禁止彩虹色状态系统

建议色板：
- background: #171716
- surface: #242321
- elevated surface: #2d2b28
- border: #46423d
- text: #eeeae1
- secondary text: #aaa49a
- muted text: #777168
- accent: #bd7454
- accent soft: #3c2d27
- success: #8c9c7d
- warning: #c4a36b
- error: #b86b67

布局：
- 信息层级优先于装饰
- 使用明确的标题、分组、分隔线和留白
- 卡片数量尽量少，避免“卡片套卡片”
- 只给真正重要的内容使用边框
- 使用 8px、12px、16px、24px 间距节奏
- 圆角克制，窗口最多 12px，控件最多 6px
- 阴影非常轻，只用于区分浮层和背景
- 不使用玻璃拟态
- 不使用强烈背景模糊
- 不使用发光边框
- 不使用漂浮的渐变球体或装饰光斑

字体：
- 优先使用 Segoe UI Variable 和 Microsoft YaHei UI
- 英文词条可以使用稍有编辑感的衬线字体，但只用于词头或引用内容
- 正文保持高可读性
- 不使用未来感、游戏感、科技感字体
- 不使用全大写标题作为主要视觉元素

按钮：
- 小而清楚
- 文字优先，图标辅助
- 默认按钮使用透明或低对比度背景
- 主要按钮使用单色实心填充
- 不使用胶囊形按钮作为默认样式
- 不使用发光 hover
- hover 只改变背景色、边框色或文字颜色
- 所有按钮必须看起来像桌面软件控件

整体感觉：
这是一个用户每天会打开几十次的阅读工具。它应该让人安静下来阅读，而不是不断提醒用户“这里有一个 AI 产品”。界面要耐看、低调、可信、稳定。
```

## HUD 提示词

```text
设计 Lemma 的 HUD 取词浮层。

这是一个贴在光标附近的窄桌面浮层，尺寸约 420px 宽。它的任务是让用户快速看懂一个词或一句话，然后继续阅读。

布局：
- 顶部是一条非常克制的标题栏
- 显示来源程序和取词方式，例如“Chrome · 选区”
- 显示一个很小的耗时信息
- 右侧放设置和关闭按钮
- 下方显示简洁的下探路径，例如：threshold › value › constraint
- 当前词条是视觉重点，但不使用巨大粗体
- 显示词头、音标、中文释义、英文解释、词性和词形变化
- 可点击的词使用细虚线下划线
- 句子卡片把中文译文放在第一层，原文作为辅助信息
- OCR 结果卡片显示识别状态、文本块数量，并提供：朗读原文、朗读译文、双栏
- “双栏”只出现在 OCR 结果卡片中
- 底部显示双击 Ctrl、Esc 等快捷键提示

视觉：
- 深石墨背景
- 暖白文字
- 暗陶土色作为唯一强调色
- 细边框
- 极轻阴影
- 不要霓虹蓝
- 不要半透明玻璃卡片
- 不要大面积发光
- 不要让 HUD 看起来像游戏 HUD
```

## 设置窗口提示词

```text
设计 Lemma 的设置窗口，尺寸约 720×580px。

将原本很长的设置列表重排成成熟桌面应用的设置界面：左侧是窄的分类导航，右侧是设置内容。

分类包括：
- 呼出方式
- 取词模式
- 本地模型
- 朗读
- 截图识别
- 截图对照
- 翻译
- 卡片显示
- 界面
- 性能

设计要求：
- 左侧导航简洁，当前项使用一条细的陶土色指示线
- 右侧每次只展示一个设置分类
- 不要把所有内容堆在同一张长页面里
- 使用分组标题、说明文字、分隔线和少量设置行
- 单选项使用清晰的选中边框，不使用发光圆点
- 开关使用窄型桌面控件，不要使用手机 App 风格的大胶囊
- 热键显示为小型键帽样式
- 模型状态使用“已安装 / 未安装”文字和小状态点
- 性能数据使用低调的三列数字，不做营销式大数字
- 不显示已经移除的“双栏热键”
- 保留 OCR 热键、朗读、翻译、卡片内容、HUD 高度和快捷键提示设置

整体感觉：
像一个专业编辑器或系统工具的 Preferences 窗口，安静、清楚、可扫描，不像 SaaS 管理后台。
```

## 双栏窗口提示词

```text
设计 Lemma 的 OCR 双栏对照窗口。

这是一个用于阅读截图、扫描件和 PDF 的长时间阅读窗口，尺寸约 1020×700px。

顶部工具栏：
- 标题“截图对照”
- 显示来源程序和 OCR 文本块数量
- 朗读原文
- 朗读译文
- 并排 / 覆盖模式切换
- 关闭按钮

并排模式：
- 左侧显示截图或文档内容
- OCR 文字框用很细的描边表示
- 右侧显示逐块译文
- 左右对应块 hover 时同步高亮
- 不要使用强烈颜色填充整块内容
- 对齐关系通过编号、间距和细边框表达

覆盖模式：
- 译文贴在原文所在位置
- 默认显示精简译文
- hover 或 focus 后显示完整译文气泡
- 气泡使用深色实色背景和细边框
- 不要使用发光气泡
- 不要把整张图片覆盖成彩色半透明层

底部词条面板：
- 只显示一条当前词条
- 点击另一个词时直接替换
- 不显示面包屑
- 提供明确的关闭按钮

整体感觉：
像一个安静的 PDF 阅读与标注工具，不像翻译网站，也不像 AI 聊天窗口。
```

## OCR 框选层提示词

```text
设计 Lemma 的全屏 OCR 框选层。

这是一个临时覆盖在桌面上的透明选择界面，用来让用户拖出需要识别的区域。

要求：
- 背景是低透明度的黑色遮罩
- 不要使用蓝紫渐变
- 不要使用霓虹科技风
- 选区矩形使用单色陶土橙或暗橄榄绿描边
- 四个角使用清楚但不夸张的角标
- 选区内部保持透明，只略微降低背景亮度
- 选区顶部显示尺寸，例如“650 × 250”
- 顶部中央显示“拖出矩形开始识别”
- 底部显示“Esc 或右键取消”
- 识别中状态使用一个低调的文字提示和小型 spinner
- 不要添加多余按钮和装饰
- 让用户一眼明白下一步是拖拽
```

## 第二轮自我修正提示词

```text
请重新检查刚才的 UI 设计，并主动删除所有“AI 生成感”。

重点检查：

1. 是否出现蓝紫渐变、青色霓虹或发光效果？
2. 是否存在过多圆角卡片？
3. 是否存在卡片套卡片？
4. 是否每个区域都在使用不同颜色？
5. 是否按钮太像移动端 App？
6. 是否设置页像 SaaS 管理后台？
7. 是否为了装饰增加了没有功能意义的图标？
8. 是否使用了过大的标题或数字？
9. 是否有明显的玻璃拟态和背景模糊？
10. 用户能否在 1 秒内看出当前词条、当前翻译状态和下一步操作？

请把所有装饰性视觉减半，保留信息层级、可读性和桌面工具感。最终效果应该更像一个经过多年打磨的专业阅读工具，而不是刚生成的 AI 产品概念图。
```
