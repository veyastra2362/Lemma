# Agent Note: 英文朗读（CMU 词典 + ARPAbet→IPA）与跟读高亮

Status: implemented

## Problem

两件：

1. **英文没有声音**。音素化只处理中文（拼音来自 CC-CEDICT），英文连一个音素都不产生，
   合成直接失败——纯英文段落点了朗读什么也不会发生。
2. **没有跟读高亮**。朗读时看不出念到哪，长段落尤其难受。

## Decision

### 英文音素化：CMU 词典 + ARPAbet→IPA

与中文那套同一个思路——**拿一份"词→音素"的词典 + 一张确定性转换表**，纯 Rust：

- 数据：`cmudict.dict`（13.5 万词，BSD 许可，3.5 MB）放进 `tts-models/`；
- 转换：ARPAbet → IPA（`AA→ɑ`、`SH→ʃ`、`NG→ŋ`…），**双元音拆成两个符号**（`AY→aɪ`）；
- 唯一需要看重音的是 `AH`：重读 `ɑ`、非重读（`AH0`）→ `ə`（schwa）。处理错了整句语调都会怪；
- 实测 Kokoro 的 zh 词表里英文 IPA 符号**全部存在**（`ɑ ɐ ɒ æ ɔ ə ɜ ɛ ɪ ʊ ʌ ʃ ʒ θ ð ʤ ʧ ɹ`），
  说明这个多语模型能吃英文 IPA；
- 中英混排按"非汉字段 → 英文词典"分段处理，两套音素串靠空格与标点拼接。

### 跟读高亮：按字符权重线性摊时间

`PlaySound` 不汇报播放位置，所以没有真正的"当前时间"。

做法：拿到合成总时长后，把**每个词的字符数**当作权重，把总时长摊到词上，
用 `setTimeout` 链逐词前进，当前词加高亮底色。顺序与合成时的分词一致。

## Alternatives considered

- **espeak-ng 做英文 G2P**：现成、覆盖广（能读生僻词与专名）。否决原因不变：
  GPL 会传染本项目的 MIT，且要带原生依赖。这是两次否决同一个选项——理由一致，不是懒。
- **直接换 Kokoro 的英文模型（v1.0）**：英文质量更对口。否决原因：
  又是 121 MB 权重，而且**它同样依赖 misaki 的英文 G2P（底层就是 espeak）**，
  并没有绕开 G2P 这个真问题；还会让"中英混排"变成跨模型拼接。
- **自己写英文 G2P 规则**（字形→音素的发音规则）：不需要数据文件。否决原因：
  英文拼写与发音的规则例外极多，规则 G2P 的错误率会让朗读听起来明显不对；
  **宁可漏读也不乱读**——查不到的词直接跳过并记日志。
- **换掉 `PlaySound`，用 cpal/rodio 自己播**：能拿到真实播放位置，高亮就精确了。
  否决原因：要引音频后端依赖并自己做混音与设备管理，为一个"高亮跟随"的精度提升
  付出一个子系统，性价比不成立；先把估算版做出来看实际体验。
- **按句朗读、逐句高亮**：比逐词容易（一次一段）。否决原因：RTF ≈ 1.1–1.5
  （合成比实时慢），逐句现合成会越读越落后；而且用户要看的是"念到哪个词"。

## Consequences

- 收益：英文与中英混排都能读出来了（`Hello world, this is a test.` → `həloʊ wɜɹld, ðɪs ɪz ə tɛst.`）；
  跟读高亮在双栏里逐词推进。
- 代价 1：**英文词典常驻约 20 MB**（3.5 MB 文本 → HashMap）。它只在第一次朗读时加载，
  但会一直留着。主进程朗读后的 RSS 从 44 MB 升到 63 MB。
- 代价 2：**只认词典里的词**。生僻词、专名、复数/时态变形查不到时会被跳过
  （日志记 `tts english skipped N word(s)`）——不做规则回退，这是刻意选择。
- 代价 3：高亮是**时间估算**，不是真同步。长词短词的权重用字符数近似，
  遇到数字、标点、读得特别快/慢的词会有偏移。
- 代价 4：`cmudict.dict` 与模型一样不进仓库（放 `tts-models/`，缺了就只有中文能读）。

## Testing

- `cargo test tts`：14 项通过（含 ARPAbet 映射、schwa 分支、词归一化）。
- 端到端（子进程路径）：
  ```
  lemma.exe --tts "Hello world, this is a test."  → 音素 həloʊ wɜɹld, ðɪs ɪz ə tɛst.  2.60 s
  lemma.exe --tts "这个 Lemma 很好用。"            → 音素 ㄓㄜ4ㄍㄜ5 lɛmə ㄏㄣ3 ㄏㄠ3ㄩㄥ4.  2.47 s
  ```
- 应用内（`LEMMA_SPEAK_SMOKE`）：`tts english dict loaded` → `audio=3.58s`，`play=Ok`。
- 跟读高亮：强制把当前词指向第 4 个词后截图，确认 `the` 带高亮底色（`LEMMA_CAPTURE_WINDOW_SMOKE=reader`）。
