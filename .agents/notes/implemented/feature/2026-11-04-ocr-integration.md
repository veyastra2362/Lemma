# Agent Note: 端侧 OCR 正式接入（M4b）

Status: implemented

## Problem

M4a 的探针证明了"能跑"（det 40 ms + rec 48 ms），但探针用的是**轴对齐包围盒 + 按框高比例外扩**的
简化后处理，只能处理水平、干净、无旋转的合成图。要进产品，需要：

1. 真正的 DB 后处理（最小外接矩形 + 官方 unclip 公式），否则斜体/透视/旋转文本全部错位；
2. 模型与会话的生命周期管理（懒加载、常驻、路径可配置）；
3. 一个不依赖窗口焦点的验证入口（沿用 `--translate` / `--segment` 的既有做法）。

## Decision

`src-tauri/src/core/ocr/` 分五个文件：`mod.rs`（编排）、`det.rs`、`postprocess.rs`、
`geometry.rs`（凸包 / 旋转卡壳 / unclip / 四点透视裁切）、`rec.rs`（含长行切段与 CTC 解码）。

关键选择：

- **不用 OpenCV、不引几何库**：凸包 + 旋转卡壳 + 四边形采样都是短算法，自己写才能单测
  （现有 20 个 OCR 相关单测，其中几何 5 个、后处理 5 个、解码 4 个）。
- **长行按 640 宽切段**：探针实测 640 明显优于 320（截断）与 1920（丢空格、慢 3 倍）。
  切段**不能加重叠**（见下）。
- **字符表末尾补空格**、det 阈值 0.3、`unclip_ratio` 1.5，都是探针标定出来的常量，写死在模块里。
- 模型放 `%APPDATA%\dev.lunar.lemma\ocr-models\`，缺失时给出可操作的报错而不是静默失败。
- 新增 `lemma.exe --ocr <image>`，`LEMMA_OCR_REPEAT=N` 可连跑区分冷热态。

## Alternatives considered

- **继续用探针那套轴对齐包围盒**：代码量减半，探针上的识别结果也不错。否决原因：
  它假设文本一定是水平的，屏幕上倾斜的标题、扫描件、带旋转的截图会直接裁错；
  而最小外接矩形 + 透视裁切正是 DB 论文的标准做法，缺了它这个模块只能算玩具。
- **切段时加重叠再拼接**：直觉上能避免切断字形。否决原因：**实测产生重复字符**
  （`canononical` / `poointing` / `原文利和译文`）——重叠区域被两段各识别一次。
  去重需要比较相邻段的公共前后缀，在中文上并不可靠；不加重叠的代价只是边界偶尔丢半个字。
- **把 OCR 做成异步命令 + 后台线程**：更符合"不阻塞 UI"。否决原因：目前只接了 CLI，
  UI 侧（框选窗口）还没接；等 M4c 接线时再决定是否放到 `async_runtime::spawn_blocking`。
  先保持同步 API，避免过早引入并发复杂度。
- **强制轴对齐框作为默认**：诊断时加过 `LEMMA_OCR_AXIS_ALIGNED` 开关，两者结果相同。
  否决原因（作为默认）：会失去旋转文本能力，且"结果相同"只在合成图上成立。

## Consequences

- 收益：主工程有了真正可用的 OCR 管线，热态 156–163 ms（900×300 三行），在 300 ms 预算内；
  几何与后处理有单测保护，后续调参不会静默破坏。
- 代价 1：`lemma.exe` 从 ~6 MB 涨到 **23.5 MB**（`ort` 静态链接，未产生独立 DLL）。
- 代价 2：OCR 会话懒加载后常驻（探针量到 ~125 MB），主进程会在首次 OCR 后明显变重；
  这条要在 M4c 接入 UI 后按 `docs/PERF.md` 口径复测并记录。
- 代价 3（**已解决**）：接完时的残余误差（丢空格、残字、行尾截断）通过基准集标定解决了。
  关键两处：`unclip_ratio` 1.5 → **3.0**（平均 CER 0.136 → 0.005），
  `REC_MAX_WIDTH` 640 → **960**（消除长行切段导致的边界残字，0.005 → **0.000**）。
  基准集与完整数据见 `docs/OCR-CALIBRATION.md`。
  行尾丢字经查是**测试图把文字画到了画布外**，加框余量反而变差（0.000→0.011），已回退。
- 遗留（M4c）：框选窗口接线、截图→OCR→双栏串联、真实截图验证、深色主题白字标定。

## Testing

- `cargo test ocr`：20 项通过——凸包剔除内部点、最小外接矩形（轴对齐与 45° 斜排）、
  unclip 外扩后中心不变、四点裁切保持宽高比、连通域检出/小噪点过滤/阅读顺序/坐标缩放、
  CTC 解码（简单序列、重复折叠、blank 分隔、空格类可达）、缓冲区长度校验、空图。
- 基准集（`tools/ocr-bench/`，7 张，覆盖深/浅底、14–28 px、中英文、单/多行）：
  **平均 CER 0.000，平均 87 ms/张**；长行图（1200×300 三行 36 pt）339 ms 冷态、三行全对。
- 无头端到端：
  ```
  lemma.exe --ocr data/ocr-test.png
  → det=52ms rec=105ms boxes=3 chars=103   热态 156–163 ms
  ```
- 冷热态拆分：`LEMMA_OCR_REPEAT=3` 首轮 429 ms（含会话创建），后两轮 156/163 ms。
